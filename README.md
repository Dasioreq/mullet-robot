# E.L. Robo

![Unity Version](https://img.shields.io/badge/Unity-6000.3.7f1-blue)
![Platform](https://img.shields.io/badge/Platform-PC%20%7C%20Mac%20%7C%20Linux-green)

## Overview
A fast-paced first-person shooter built with Unity, where your time's constantly running out and you gotta go fast.

### Features
- Procedurally generated levels
- Upgradeable weapons
- Perks and skills
- A retro, PSX aesthetic
